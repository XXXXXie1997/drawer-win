# drawer

**随放随取**

drawer 是一个二维内容抽屉。可以将文本、文件、文件夹和截图等放入，自由整理位置并在需要时随时取出。

收集网页片段、暂存截图，放入文本并编辑、或在多个窗口之间传递文件，都可以在同一块画布上完成。

## 主要功能

- **随时呼出**：鼠标靠近屏幕边缘显示把手，点击或拖入内容即可展开，离开后自动收起。支持顶部、左侧和右侧停靠。
- **自由整理**：文字、文件和图片混合摆放，支持多选、框选和整体移动；对象自动吸附网格、避让重叠。
- **文字直接编辑**：双击修改文字，也可以只选取其中一段复制或拖出。
- **跨应用取用**：将内容复制或拖到支持的应用中，抽屉里的对象继续保留。
- **可缩放画布**：平移、缩放查看内容，也能通过“显示全部”找回画布上的所有对象。
- **自动保存**：重启后恢复内容和布局，支持会话内撤销与重做。内容保存在本机。

文件以引用方式放入抽屉，从抽屉中移除不会删除源文件。

## 开始使用

适用于 **Windows 11 x64**，双击 `启动 drawer.cmd` 即可运行。

1. 将鼠标移到设置的停靠位置，点击弹出的黑色区域。
2. 拖入内容，或使用 `Ctrl+V` 粘贴；拖动对象整理位置。
3. 需要时复制、拖出，或双击文字选取其中一部分。

右键拖动画布可以平移，`Ctrl+滚轮` 可以缩放。更多操作在画布右键菜单中，停靠位置可通过通知区域图标里的“偏好设置”调整。
